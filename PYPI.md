# system-spec-ref

Contract-first system specification toolkit: metamodel validator (`system-spec`), JSON Schema, greenfield/brownfield workflows, examples and formal-model skill guides (TLA+, Alloy, Modelable).

```bash
pip install system-spec-ref
system-spec --version
system-spec spec.yaml --stage architecture
system-spec export ./system-spec    # offline docs, examples, skills, WIRING.md
```

* After export, read `WIRING.md` to connect the toolkit to your project, agent instructions and skills, and to upgrade.
